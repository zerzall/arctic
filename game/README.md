# Rainbow Rails

An endless 3D runner in one HTML file (Three.js r128 from cdnjs). Open `game/index.html` in a browser to play.

- **Controls:** ← → switch lanes, ↑ / Space jump, ↓ roll, P pause. On touch screens, swipe.
- **Worlds:** Sunset Boulevard → Palm Coast → Candy Canyon → Neon Night → Frost Peaks. A new world starts every 1,000 m, then the loop repeats. Each world raises the score multiplier.
- **Power-ups:** coin magnet, super jump sneakers (high enough to land on trains), double score.
